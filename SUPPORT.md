# Support

900API is community-maintained open source software. Support is provided through GitHub when maintainer time is available.

## Before Opening an Issue

1. Read the [README](README.md) and [documentation index](docs/README.md).
2. Search open and closed issues for the same behavior.
3. Confirm you are using the latest release.
4. Reproduce the issue with a non-sensitive endpoint or a local mock when possible.
5. Run `./scripts/verify-local.sh` if you are reporting a source-build failure.

## Bug Reports

Use the bug report form and include:

- 900API version
- operating system and architecture
- installation method
- exact steps to reproduce
- expected and actual behavior
- relevant error text with credentials and private URLs removed

Do not upload private collections, environment files, local databases, or screenshots containing tokens.

## Usage Questions

Use GitHub Discussions when enabled. If Discussions are not enabled, open a question issue. Describe the workflow you are trying to complete, not any production secret or customer data.

## Security

Security reports do not belong in public issues or discussions. Follow [SECURITY.md](SECURITY.md) and email `security@900labs.com`.
